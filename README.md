# movie_recommendation
This project is a content-based movie recommendation system built using Python. It suggests similar movies based on genre using vectorization and cosine similarity. The project demonstrates basic machine learning concepts like data preprocessing and similarity analysis.

## 📌 Overview

This project is a **content-based movie recommendation system** built using Python.
It recommends similar movies based on genre similarity using machine learning techniques.

---

## 🧠 How It Works

* Movie genres are converted into numerical vectors using **CountVectorizer**
* **Cosine similarity** is used to compare movies
* Top 5 most similar movies are recommended
